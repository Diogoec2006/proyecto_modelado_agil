📜 Esquema SQL para Base de Datos en Supabase

Para enlazar este sistema a tu base de datos en Supabase:

  1. Entra a tu consola de Supabase y selecciona tu proyecto.
  2. Abre la sección SQL Editor en la barra lateral izquierda.
  3. Pega el código SQL inferior y haz clic en RUN.
  4. En tu archivo .env coloca tu SUPABASE_URL y SUPABASE_KEY.
